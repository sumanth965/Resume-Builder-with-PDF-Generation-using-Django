# 03-01: Foundation & Design System

This plan establishes the modern styling foundation using Tailwind CSS and updates the core application layout to support the new sidebar-based editor experience.

## Tasks

<task id="frontend-deps-01">
<title>Static Files & CDN Setup</title>
<read_first>
- `resume_project/settings.py`
- `resume_app/templates/base.html`
</read_first>
<action>
1. Update `settings.py` to ensure `STATICFILES_DIRS` and `STATIC_ROOT` are correctly configured.
2. Update `base.html` to include:
   - Tailwind CSS (via Play CDN for development).
   - Google Fonts (Inter/Outfit).
   - Alpine.js and HTMX CDNs.
   - A unified `<main>` layout with a persistent background theme.
</action>
<acceptance_criteria>
- Project renders with Inter font.
- Tailwind utility classes (e.g., `bg-slate-50`) are active.
- Browser console shows Alpine and HTMX are loaded.
</acceptance_criteria>
</task>

<task id="layout-01">
<title>Modern Responsive Layout</title>
<read_first>
- `resume_app/templates/base.html`
</read_first>
<action>
1. Refactor `base.html` into a professional, dashboard-style layout.
2. Implement a responsive navigation bar or header.
3. Define the main content container as a flexible flex/grid layout to host the future 2-pane editor.
</action>
<acceptance_criteria>
- Navigation bar is functional and responsive.
- Content area transitions smoothly between mobile (stacked) and desktop (side-by-side).
- Modern slate/blue color palette is consistent across the frame.
</acceptance_criteria>
</task>

## Verification

- **Must-have**: Visual change is immediate and significant (premium feel).
- **Must-have**: HTMX and Alpine are verified via `htmx.on('configRequest', ...)` or simple `x-data` toggle.
