# 06-03: Theme Switcher UI

This plan adds the ability for users to select their preferred theme directly in the editor sidebar.

## Tasks

<task id="theme-ui-01">
<title>Theme Selector Implementation</title>
<read_first>
- `resume_app/templates/form.html`
</read_first>
<action>
1. Add a new Tab "Theme" to the sidebar in `form.html`.
2. Implement a selection UI (either Radio cards or a Visual Grid).
3. The selection must update a hidden input `template_name`.
4. The change event should trigger the HTMX live preview refresh instantly.
</action>
<acceptance_criteria>
- Clicking a theme card instantly changes the appearance of the Live Preview.
- The selected theme is remembered during the session (via form state).
</acceptance_criteria>
</task>

## Verification

- **Must-have**: Theme change triggers a smooth HTMX transition in the preview window.
- **Must-have**: The selected theme is preserved when the user hits "Download PDF".
