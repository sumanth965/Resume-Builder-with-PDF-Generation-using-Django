# 06-01: Modern Template Implementation & Architecture

This plan refactors the existing layout into a "Theme" system and solidifies the primary "Modern" theme.

## Tasks

<task id="theme-infra-01">
<title>Theme Infrastructure Setup</title>
<read_first>
- `resume_app/models.py`
- `resume_app/views.py`
</read_first>
<action>
1. Add `template_name` field (CharField, default='modern') to the `Resume` model.
2. Update `_get_resume_context` help in `views.py` to extract `template_name` from POST.
3. Create `resume_app/templates/themes/` directory.
</action>
<acceptance_criteria>
- Database migration applied successfully.
- `template_name` is correctly captured in the view context.
</acceptance_criteria>
</task>

<task id="modern-theme-01">
<title>Extract Modern Theme Partial</title>
<read_first>
- `resume_app/templates/partials/preview_pane.html`
</read_first>
<action>
1. Move the contents of `preview_pane.html` into `resume_app/templates/themes/modern.html`.
2. Update `preview_pane.html` to dynamically include the selected theme:
   `{% include 'themes/'|add:template_name|add:'.html' %}`
3. Do the same for `resume_print.html`.
</action>
<acceptance_criteria>
- The Live Preview still renders the "Modern" theme by default.
- No regression in styling or functionality.
</acceptance_criteria>
</task>

## Verification

- **Must-have**: Existing resumes still render correctly using the 'modern' identifier.
- **Must-have**: Template selection is passed through to the async PDF task.
