# 06-02: Professional & Minimal Theme Implementation

This plan implements the alternative visual themes for the resume builder.

## Tasks

<task id="professional-theme-01">
<title>Professional Theme implementation</title>
<read_first>
- `resume_app/templates/themes/modern.html`
</read_first>
<action>
1. Create `resume_app/templates/themes/professional.html`.
2. Design: 
   - Centered header.
   - Serif fonts (EB Garamond/Lora).
   - Dense layout with single-line item headers.
   - Minimalist black dividers.
</action>
<acceptance_criteria>
- Theme renders correctly when `template_name='professional'` is provided.
- Styling distinct from Modern theme.
</acceptance_criteria>
</task>

<task id="minimal-theme-01">
<title>Minimal Theme implementation</title>
<action>
1. Create `resume_app/templates/themes/minimal.html`.
2. Design:
   - High whitespace.
   - Left-aligned content.
   - Sans-serif light fonts.
   - No heavy accents or colored headers.
</action>
<acceptance_criteria>
- Theme renders correctly when `template_name='minimal'` is provided.
</acceptance_criteria>
</task>

## Verification

- **Must-have**: Both themes are responsive.
- **Must-have**: WeasyPrint renders the specific fonts correctly in the final PDF.
