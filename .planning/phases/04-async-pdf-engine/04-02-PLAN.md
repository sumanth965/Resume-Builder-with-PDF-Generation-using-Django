# 04-02: High-Fidelity Rendering (WeasyPrint)

This plan implements the high-quality PDF rendering engine using WeasyPrint and integrates it into the background task workflow.

## Tasks

<task id="weasyprint-engine-01">
<title>WeasyPrint Implementation</title>
<read_first>
- `resume_app/views.py`
- `resume_app/tasks.py`
</read_first>
<action>
1. Create `resume_app/templates/resume_print.html` with print-specific CSS (@page size A4).
2. Implement PDF generation logic in `tasks.py` using `weasyprint.HTML`.
3. Update `views.py` to trigger the task instead of rendering PDF synchronously.
4. Implement media file storage for generated PDFs in `media/resumes/`.
</action>
<acceptance_criteria>
- Task successfully writes a PDF file to the media directory.
- PDF supports modern CSS features (Flexbox/Gradients).
- `views.py` returns the `task_id` for tracking.
</acceptance_criteria>
</task>

<task id="media-config-01">
<title>Media File Configuration</title>
<read_first>
- `resume_project/settings.py`
- `resume_project/urls.py`
</read_first>
<action>
1. Define `MEDIA_URL` and `MEDIA_ROOT` in `settings.py`.
2. Add media serving to `urls.py` (for development only).
</action>
<acceptance_criteria>
- Files in `MEDIA_ROOT` are accessible via `MEDIA_URL` in the browser.
</acceptance_criteria>
</task>

## Verification

- **Must-have**: PDF output is visually superior to the legacy version.
- **Must-have**: Parallel PDF generation works without blocking the web worker.
