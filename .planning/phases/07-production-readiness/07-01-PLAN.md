# 07-01: Dashboard & Resume Listing

This plan implements the control center for the application, allowing users to view and manage their saved resumes.

## Tasks

<task id="dashboard-ui-01">
<title>Dashboard Implementation</title>
<read_first>
- `resume_app/views.py`
- `resume_app/urls.py`
</read_first>
<action>
1. Create `resume_app/templates/dashboard.html`.
2. Design a "Bento-style" grid listing all Resumes from the database.
3. Each card should show the Name, Email, and Template used.
4. Add "NEW RESUME" button prominently.
</action>
<acceptance_criteria>
- Dashboard accessible at `/`.
- Correct listing of saved resumes.
- "New Resume" button redirects to the editor.
</acceptance_criteria>
</task>

<task id="dashboard-logic-01">
<title>Resume List View</title>
<action>
1. Add `resume_list` view in `views.py`.
2. Map it to the root path `/` and rename the existing root if necessary.
3. Order resumes by ID descending.
</action>
<acceptance_criteria>
- Navigating to localhost:8000 shows the dashboard.
</acceptance_criteria>
</task>

## Verification

- **Must-have**: Dashboard renders quickly.
- **Must-have**: Empty state (when no resumes exist) is handled gracefully.
