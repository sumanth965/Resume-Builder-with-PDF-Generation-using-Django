# 02-01: API Core Implementation

This plan implements the Django REST Framework (DRF) layer, providing a modern, scalable API for resume management.

## Tasks

<task id="api-setup-01">
<title>DRF Installation & Configuration</title>
<read_first>
- `requirements.txt`
- `resume_project/settings.py`
</read_first>
<action>
1. Install `djangorestframework` and `django-filter`.
2. Add `rest_framework` and `django_filters` to `INSTALLED_APPS` in `settings.py`.
3. Configure `REST_FRAMEWORK` settings:
   - Default permission: `AllowAny` (for development, update later).
   - Default filter backends: `DjangoFilterBackend`, `SearchFilter`.
   - Default pagination: `PageNumberPagination` (limit 10).
</action>
<acceptance_criteria>
- DRF is installed and recognized by Django.
- `python manage.py check` passes.
- Accessing `/api/` (once URLs are set) shows the DRF browsable API.
</acceptance_criteria>
</task>

<task id="serializers-01">
<title>Relational Serializers</title>
<read_first>
- `resume_app/models.py`
</read_first>
<action>
1. Create `resume_app/serializers.py`.
2. Define `EducationSerializer` and `ExperienceSerializer` (standard `ModelSerializer`).
3. Define `ResumeSerializer` including nested fields for `education_entries` and `experience_entries`.
4. Implement writable nested logic in `ResumeSerializer.update()` and `.create()` to handle related data blocks.
</action>
<acceptance_criteria>
- Serializers represent all fields from models.
- `ResumeSerializer` output includes education and experience arrays.
- Serializers enforce the date and required field validations.
</acceptance_criteria>
</task>

<task id="api-views-01">
<title>ViewSets & Routing</title>
<read_first>
- `resume_app/serializers.py`
- `resume_project/urls.py`
</read_first>
<action>
1. Create `resume_app/api.py` (or use `views.py`).
2. Implement `ResumeViewSet` with `queryset = Resume.objects.prefetch_related(...)`.
3. Configure `filterset_fields = ['name', 'email']` and `search_fields = ['name', 'programming_languages', 'tools']`.
4. Use `DefaultRouter` to register API routes.
5. Update `resume_project/urls.py` to include `api/v1/` path.
</action>
<acceptance_criteria>
- GET `/api/v1/resumes/` returns a list of resumes.
- POST `/api/v1/resumes/` with nested JSON successfully creates a resume and related entries.
- Searching via `?search=Python` works as expected.
</acceptance_criteria>
</task>

## Verification

- **Must-have**: Browsable API is accessible.
- **Must-have**: CRUD operations work for the nested Resume structure.
