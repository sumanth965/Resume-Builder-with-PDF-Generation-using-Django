# 01-01: Database Setup & Related Models

This plan establishes the technical foundation for the upgrade by configuring environment variables for future PostgreSQL compatibility and implementing the new relational database schema.

## Tasks

<task id="db-setup-01">
<title>Environment Configuration & Dependencies</title>
<read_first>
- `requirements.txt`
- `resume_project/settings.py`
</read_first>
<action>
1. Install `django-environ` and `psycopg2-binary` (for PostgreSQL support).
2. Create `.env.example` in the project root with placeholders for `DATABASE_URL`, `SECRET_KEY`, and `DEBUG`.
3. Create a local `.env` file (ensure it's in `.gitignore`).
4. Update `resume_project/settings.py` to use `environ` for `DATABASE_URL` (defaulting to SQLite if no URL is provided).
</action>
<acceptance_criteria>
- `requirements.txt` contains `django-environ` and `psycopg2-binary`.
- `.env.example` and `.env` exist.
- `settings.py` successfully loads configuration from `.env`.
- `python manage.py check` passes with no database errors.
</acceptance_criteria>
</task>

<task id="models-01">
<title>Relational Schema Implementation</title>
<read_first>
- `resume_app/models.py`
</read_first>
<action>
1. Define the `Education` model with fields: `resume` (ForeignKey to Resume), `institution`, `degree`, `start_date`, `end_date`, `marks`.
2. Define the `Experience` model with fields: `resume` (ForeignKey to Resume), `company`, `role`, `start_date`, `end_date`, `description`.
3. Keep existing flat text fields in the `Resume` model as backups.
4. Run `python manage.py makemigrations` and `python manage.py migrate`.
</action>
<acceptance_criteria>
- `resume_app/models.py` contains `Education` and `Experience` classes.
- Migrations are generated and applied.
- `db.sqlite3` shows the new tables (e.g., `resume_app_education`).
</acceptance_criteria>
</task>

## Verification

- **Must-have**: `Resume` exists and is related to multiple `Education` and `Experience` records.
- **Must-have**: App runs using SQLite by default but supports PostgreSQL via `.env`.
